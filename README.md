# Project 2 in TMA4268 Statistical Learning
The project aims to develop and evaluate statistical and machine learning models for predicting a borrower's loan status (i.e., if loan is fully paid or defaults) based on a set of financial and demographic predictors. 

Dataset is sourced from https://www.kaggle.com/datasets/udaymalviya/bank-loan-data/data.
